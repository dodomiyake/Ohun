# Ohun brand assets

## Included variants

- `ohun-icon.svg` — transparent master icon.
- `ohun-icon-light.svg` — light app-tile variant.
- `ohun-icon-dark.svg` — dark app-tile variant.
- PNG exports at 1024, 512, 192, 180, 64 and 32 pixels.

## Recommended use

- App stores and PWA manifest: 512px and 192px light PNGs.
- Apple touch icon: 180px light PNG.
- Favicons: 64px and 32px transparent PNGs.
- Dark-mode launchers: dark PNGs.
- Web and print: SVG master whenever supported.

The icon has generous internal safe space and remains legible at favicon size.
